# Install Brand Designer

This repo is generated by Agent Builder and is safe to review before installation.

## Local test

```bash
npm test
node src/agent.cjs --dry-run --api=http://127.0.0.1:3001
```

## Dashboard registration

Review and copy/merge these templates into the target dashboard deployment:

- `config/dashboard-agent.json` → `config-core/active-agents.json`
- `config/agent-requirements.template.json` → `config-core/agent-requirements.json`
- `config/scheduled-jobs.template.json` → `config-core/scheduled-jobs.json`

## OpenClaw runtime registration

Installation is not complete until this repo is registered in both OpenClaw layers:

1. Add the repo path to `skills.load.extraDirs` so `openclaw skills` shows this skill as ready.
2. Add an `agents.list` entry using `openclaw/registration.template.json` so `openclaw agents list --bindings` shows `brand-designer` as its own isolated runtime agent.

A skill-only install is incomplete for SquidBot production agents.

Do not overwrite deployment config blindly. Merge by agent id: `brand-designer`.
