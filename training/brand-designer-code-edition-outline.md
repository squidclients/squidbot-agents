# Training Outline: From No Agent to Brand Design with Codex or Claude Code

## Outcome

Turn a coding agent into a brand-aware creative director connected to an external image API.

1. The division of labour: Codex/Claude reads context, writes direction, builds code-native assets, and runs QA; Higgsfield/OpenAI/custom providers render raster imagery.
2. MET filter: makes money by producing campaign-ready creative; creates efficiency with repo-based brand context and repeatable workflows; saves time by keeping briefs, revisions, and QA together.
3. Before state: generic coding agent with no brand evidence and no image provider.
4. Install: copy the code edition, configure the provider adapter, and run `doctor`.
5. Seasoning: use the same intake/profile/assets as the SquidBot edition so results are comparable.
6. First generation: write a structured brief, call the adapter, inspect the returned artifact, and revise.
7. Code-native use cases: landing-page sections, SVG diagrams, deck templates, HTML email graphics, and automated resize/export scripts.
8. Raster use cases: campaign concepts, editorial hero art, thumbnails, ads, and presentation covers.
9. Provider swapping: keep workflow stable while changing Higgsfield/OpenAI/custom endpoints.
10. Safety and QA: local secrets, no invented logos, bounded revisions, saved evidence, and human approval.
11. Choosing an edition: persistent business operator and dashboard workflow versus hands-on repo workflow for builders.
12. First-win exercise: produce the same brief in both editions and compare quality, time, and repeatability.
